# Project Reflection

Working on this project helped me better understand how data visualization depends on both technical choices and design choices. At the beginning, I thought of the map mostly as a way to show housing prices around San Luis Obispo County, but as I developed it, I realized that the visualization also needed to guide comparison. Adding the ability to select a ZIP market and compare it to the local median made the project feel more analytical instead of just descriptive. It helped me see how interaction can make a map more useful because the viewer can ask their own questions instead of only reading a fixed chart.

One thing I learned was how important color choice is in communicating data clearly. The first color scheme was visually busy and did not have a clear meaning. Changing it to move from lighter colors to darker colors made the map easier to interpret because higher values naturally appear more visually prominent. I also learned that small visual details, such as line weight, labels, and table alignment, can affect whether a project feels polished and trustworthy.

The most challenging part of the project was balancing geographic accuracy with readability. The map uses Zillow ZIP-level housing data and Census ZCTA boundaries, which meant I had to be careful about explaining that ZCTAs are generalized Census representations of ZIP Code areas. Another challenge was making the dashboard interactive without making it confusing. The selected market needed to update the map, summary cards, trend chart, and comparison table consistently, so I had to think about how each part of the page related to the others.

Overall, this project taught me that a good visualization is not just about putting data on a screen. It requires decisions about audience, context, visual hierarchy, and honesty about what the data can and cannot show. I became more aware of how design and analysis support each other, and I feel more confident building a data product that is both informative and understandable.
